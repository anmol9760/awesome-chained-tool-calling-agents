# Tutorials and Learning Resources

Learning resources for understanding LLM agents, tool calling, multi-agent systems, agent safety, and failure analysis.

## 1. Hugging Face Agents Course

A practical introduction to AI agents, tools, and agentic workflows.

- https://huggingface.co/learn/agents-course

**Useful for:** Understanding the fundamentals of AI agents and tool use.

---

## 2. LangChain Documentation

Documentation and tutorials covering LLM applications, agents, tools, and workflows.

- https://python.langchain.com/

**Useful for:** Learning how to implement tool-calling agents.

---

## 3. LangGraph Documentation

Documentation and tutorials for building stateful, graph-based agent workflows.

- https://langchain-ai.github.io/langgraph/

**Useful for:** Understanding agent state, workflow transitions, checkpoints, and recovery.

---

## 4. Microsoft AutoGen Documentation

Documentation for building multi-agent applications and agent collaboration workflows.

- https://microsoft.github.io/autogen/

**Useful for:** Learning multi-agent communication and orchestration.

---

## 5. LlamaIndex Documentation

Tutorials for building LLM applications connected to external data and tools.

- https://docs.llamaindex.ai/

**Useful for:** Understanding retrieval-augmented and tool-augmented agents.

---

## 6. ReAct

The ReAct approach combines reasoning and acting for language-model agents.

- Paper: https://arxiv.org/abs/2210.03629

**Useful for:** Understanding the reasoning-and-action loop used by many tool-using agents.

---

## 7. Toolformer

Introduces an approach where language models learn to use external tools.

- Paper: https://arxiv.org/abs/2302.04761

**Useful for:** Understanding automated tool invocation.

---

## 8. WebArena

A realistic environment for learning about and evaluating autonomous web agents.

- Paper: https://arxiv.org/abs/2307.13854
- Repository: https://github.com/web-arena-x/webarena

**Useful for:** Studying long-horizon autonomous agent behavior.

---

## Suggested Learning Path

1. Understand basic LLM agents.
2. Learn tool calling.
3. Study ReAct and Toolformer.
4. Build a simple agent using LangChain or LangGraph.
5. Learn multi-agent orchestration using AutoGen or CrewAI.
6. Study agent safety and prompt injection.
7. Explore agent benchmarks such as AgentBench and WebArena.
8. Study failure modes and methods for verification and human oversight.
