# Datasets and Benchmarks

Datasets and benchmarks useful for evaluating the reliability, safety, tool use, and failure modes of LLM-based agents.

## Agent Safety and Reliability

- **Agent-SafetyBench** — A benchmark for evaluating the safety of LLM agents across different scenarios.
  - https://arxiv.org/abs/2412.14470

- **AgentBench** — A benchmark for evaluating large language models in agent-oriented environments.
  - https://arxiv.org/abs/2308.03688

## Tool-Using Agents

- **ToolEmu** — A sandbox-based framework for identifying risks associated with language-model agents using tools.
  - https://arxiv.org/abs/2309.15817

- **ToolLLM / API-Bank resources** — Resources for evaluating LLMs on real-world API/tool use.
  - https://arxiv.org/abs/2307.16789

## Web and Long-Horizon Agents

- **WebArena** — A realistic web environment for evaluating autonomous web agents.
  - https://arxiv.org/abs/2307.13854

- **METR Long-Horizon Task Evaluations** — Resources for measuring AI ability to complete long software tasks.
  - https://arxiv.org/abs/2503.14499

---

## Why These Resources Matter

These datasets and benchmarks can be used to study:

- Agent safety failures
- Tool-selection errors
- Incorrect tool parameters
- Prompt-injection vulnerabilities
- Long-horizon task failures
- Error propagation across agent trajectories
- Reliability of autonomous agents
